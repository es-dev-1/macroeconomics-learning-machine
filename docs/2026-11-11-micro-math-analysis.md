# Math needed for Mikroökonomie I

**Last updated**: 2026-11-11
**Source**: Mikroökonomie I, Sommersemester 2025, Prof. Dr. Florian Hett, full slideset (662 slides, file in Downloads)

## Summary

The course follows the standard intermediate micro sequence: budget, preferences, utility, optimal choice, demand, Slutsky, elasticities and welfare, intertemporal choice, uncertainty, production, costs, competitive firms, monopoly, price discrimination, game theory, and oligopoly. Part 0 topics 0.1 to 0.6 already covered powers, logs, derivatives, curve sketching, partial derivatives, the Lagrange method, elasticity, and present value. The tasks also needed ten techniques that were missing or only partly covered, so topics 0.7 to 0.10 were added to the board on 2026-11-11. Integrals and matrices are not needed: every surplus is a triangle and payoff tables are read, not calculated.

## Notation the course uses

- Consumer: x1, x2, p1, p2, m; GRS (never MRS); MU1, MU2; Lagrange L = U − λ(p1x1 + p2x2 − m) with numbered BEO.
- Firms: Q = F(K, L), MP_L, MP_K, TRS; costs FC, VC, TC, AFC, AVC, ATC, MC, LAC, LMC; revenue TR, MR; profit Π; capital P and Q.
- Cost minimization: C = rK + wL + λ(F(K, L) − Q0).
- Numbers: decimal comma and thousands point.
